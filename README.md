# rails-accessibility

[![ClawHub Skill](https://img.shields.io/badge/ClawHub-Skill-blue)](https://clawhub.ai/djc00p/skills/rails-accessibility)

Practical a11y patterns for Rails/Stimulus/Hotwire apps - ERB partials, axe-core CI, color contrast, modals, dynamic content. Not WCAG theory. Use when: building or auditing accessible forms, modals, navigation, or live-updating content; setting up axe-core in CI or RSpec; fixing Tailwind/oklch contrast failures; making Turbo Frame/Stream updates announce to screen readers; or when an accessibility spec breaks because public-page copy changed.
